## Recorded interactions

- Route/contributor form -> camera setup; required browser fields prevent empty submission.
- Open live scan -> focus moves to close; start -> camera, session and GPS watcher.
- Inaccurate GPS -> upload withheld with explicit wait state.
- Simulated failed frame transport -> identical sequence/metadata retried, saved receipt displayed.
- Stop -> server session becomes stopped. Close -> focus returns to open button.
- End/change route -> setup form returns and active media cleanup runs.
- Manual camera capture -> image evidence and GPS populated only at capture.
- File video -> preview only, no device GPS registration.
- Light/dark toggle -> both themes and portrait/landscape layouts tested.
- Mobile menu -> Tab stays inside dialog; Escape returns focus; resize closes drawer.
- Existing report/repair/history/map flows -> previous E2E lifecycle remains passing.

Mocked browser capture proves UI contracts only. A separate real-checkpoint smoke
test used a temporary database and saved a candidate area from two sample frames.
Physical phone permissions/GPS, real driving clips and field accuracy remain unverified.
