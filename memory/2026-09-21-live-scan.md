# Live scan debug report, 2026-09-21

## Symptom

Live camera opened, but the frame analysis did not continue on a real media
stream.

## Root cause

`live-camera.tsx` attached a `streamRequest.then` cleanup before assigning the
resolved stream to `streamRef`. The callback observed `activeRef.current ===
false` and `streamRef.current === null`, then stopped the camera track during the
normal startup race. The existing test used a trackless mock, so it did not
detect this lifecycle bug.

## Fix

Camera startup now owns a cancellation callback. A resolved stream is accepted
before playback and is only stopped by the late-resolution cleanup when startup
was actually cancelled or timed out. Normal startup no longer stops its track.

## Evidence

- Regression test failed before the fix with one premature `track.stop()` call.
- The same regression test passes after the fix and observes exactly one stop on
  explicit scan shutdown.
- Full Playwright suite: 7 passed.
- API suite: 34 passed.
- Web build passed.
- Web lint passed with four existing `next/image` warnings and zero errors.
- Real HTTPS proxy inference probe returned HTTP 200 with a detected pothole.
